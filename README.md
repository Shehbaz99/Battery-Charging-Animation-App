# 🔋 Battery Charging Animation

A modern Android application built with **Kotlin** that enhances the charging experience through customizable charging animations, battery monitoring, and real-time charging status updates.

The application detects charging events using Android system broadcasts and displays visually engaging charging animations while providing useful battery information such as charging status, battery level, temperature, and health.

---

### ⚡ Charging Animation Effects

* Full-screen charging animations

# 🎯 Core Functionalities

## Charging State Detection

The application monitors system charging events using Android BroadcastReceivers.

Supported events:

* Charger Connected
* Charger Disconnected
* Charging Status Updates
* Battery Level Changes

---

## Charging Animation Engine

Displays charging animations when power is connected.

Features include:

* Full-screen charging overlays
* Lottie animation support
* Dynamic battery percentage display
* Smooth animation rendering

---

## Battery Information Dashboard

Provides useful battery insights such as:

* Battery Percentage
* Battery Temperature
* Battery Health
* Charging Status
